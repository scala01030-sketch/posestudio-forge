# Pose Studio 0.1.6 操作流程修复

本版仅改进静态摆拍操作，保留已有模型适配、双层皮肤、连续肘膝、批量冻结和服务器数量限制。

## 摄影与编辑往返

摄影机面板提供“进入自由摄影”和“返回动作编辑”。进入自由摄影后按当前绑定的“打开/关闭编辑面板”，或按 Esc，返回最近的 Actor / Pose 编辑模式。拍照状态可用当前拍照键、编辑面板键或 Esc 返回。切换保留选中对象、骨骼、姿势、Actor 位置、冻结状态、相机 XYZ / Pitch / Yaw / Roll / FOV。

旧版面板直接比较固定 F6/F7/F8，实例的启动键实际为 F4，导致提示与操作不一致。现在键盘事件与面板回退路径均读取当前 KeyMapping，且每次按键只处理一次。鼠标绑定也使用当前 KeyMapping。输入处理仅接管 Studio 的主编辑页和无面板世界视图，不干扰普通菜单输入。

自由摄影时显示一条返回操作提示。实际原包测试发现，hideGui 会使 Forge RenderGuiEvent.Post 不执行；因此提示接入 Minecraft 已有 GUI 绘制收尾阶段，继续使用原生 GuiGraphics。Capture 不绘制这条提示，不新增世界渲染器。

## 编辑视角

中央视口顶部提供前视、后视、左视、右视。视角相对于当前主对象的 Actor Yaw，镜头对准其包围盒中心，按体型及当前 FOV 调整距离，并将 Pitch / Roll 归零。使用 Minecraft 原生透视摄影机，不是独立正交渲染。只移动摄影机，保留 Actor 与 Pose，视角切换也可撤回。

## 世界轴位移

Actor 模式显示红 X、绿 Y、蓝 Z 平移手柄。右侧选择当前位移轴；在模型上左拖或右拖使用该轴，直接拖手柄可以选轴并移动。空白处仍用于镜头操作。Pose 模式的旋转轴和 Actor 位移轴独立保存，互不混用。

拖动沿世界坐标轴求射线与轴线的最近参数。只有选中的一个坐标改变，多选对象使用同一位移，姿势与相机不变。接近镜头朝向的轴显示偏移深度手柄，使用上下拖动控制深度；从正面也能操作 Z。回到起始拖动位置会重新发送原位置。

## 十步撤回

历史改为最多 10 个完整调整，超过时丢弃最旧记录。旋转环、Actor 多选位移、面板镜头拖动的一次按下到松开作为一次调整；数值应用、视角切换、姿势加载各记一次。顶部“撤回”或 Ctrl+Z 逐步恢复。切换模式、摄影、拍照和选择不会清空历史；恢复某个冻结实体、删除临时对象和退出 Studio 会清空，防止旧记录操作已经释放的对象。没有 Redo、时间轴或动画。

## 动态提示

编辑页页脚与自由摄影提示在每次绘制时读取启动、编辑面板、拍照三个动作的当前键位，中文和英文都不再写死 F6/F7/F8。等待主画面的提示也读取当前启动键。固定的鼠标编辑手势、Ctrl+Z、Ctrl+S/O、Enter 和 Esc 是编辑器快捷操作，未新增对应的可配置动作。自由摄影 WASD、Space/Shift、Q/E、Ctrl、方括号仍沿用此前控制方式。

实际验证仅使用指定 Vanilla-tacz 原实例、新建验收世界和离线 StudioTest，保留原模组、资源包与光影；具体结果见 ACCEPTANCE-0.1.6.md。

本次实例已关闭 FA+Player。旧验收只读取 CEM 子节点的网格记录，不能据此判断原版肢体是否正确变形；现在原版肢体发出的顶点也记录同样的变形签名，外层检查使用实际工作的平面或 Skin Layers 3D 体素路径。此记录只用于确认渲染结果，不改变顶点位置、UV、法线、材质或连续弯曲算法。
