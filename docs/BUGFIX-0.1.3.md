# v0.1.3：双层皮肤与鼠标视口操作

日期：2026-09-26。所有源码、构建、运行目录与证据位于 `E:\PoseStudio`。

## 原因与修复

普通玩家外层已可以映射到对应的基本 ModelPart，但注册依赖字段扫描顺序。现在帽层、外套、袖子、裤腿显式共享 head / body / arm / leg 的骨骼键名，使用同一个 Pose。没有将皮肤图片压平成单层，透明区域和外层形状仍保留。

Skin Layers 3D 1.11.2 使用独立 CustomizableModelPart / Mesh 渲染，体素外层不经过 Minecraft ModelPart.compile。它的肩、髋能跟随 ModelPart.transform，但肘膝的连续网格变形挂钩没有执行，导致底层弯曲、外层保持直线。

新增可选网格桥接，将最终提交的体素顶点还原到当前肢体的模型空间，执行与底层相同的 BendMath，再提交至原来的 VertexConsumer。体素偏移、缩放、皮肤 UV、颜色、光照和纹理保持来自原模组。侧面细分使体素和后备长面都能形成连续圆弧；共享模型和第三方网格缓存不被持久修改。主画面及光影阴影各使用当次矩阵，阴影不覆盖编辑节点。

## 鼠标操作

| 位置与手势 | 行为 |
|---|---|
| 中央视口滚轮 | FOV 缩放；向上滚动放大 |
| 中央视口按中键上下拖动 | FOV 缩放；向上拖动放大 |
| 中央视口空白处按左键拖动 | 摄影机 Pitch / Yaw |
| 中央视口按右键拖动 | 摄影机沿画面平面平移，含 Roll 的平面方向 |
| 骨骼节点 / XYZ 环左键操作 | 优先选中骨骼 / 编辑关节 |
| 左侧列表滚轮 | 只滚动角色或骨骼列表 |

摄影机操作不改变 Actor 的位置或关节 Pose。FOV 范围仍为 10–150°。中英文底部操作提示已更新。

## 验证方法与边界

独立验收夹具提供 64×64 双层皮肤：蓝色底层与橙白外层，外层留有透明孔，便于辨认。测试皮肤和测试 Mixin 只在 verification-fixtures JAR 中，正式模组不替换用户皮肤。对 classic / slim 分别检查，实际统计四个肢体的普通或 3D 外层弯曲顶点，不只检查骨骼数据。

游戏内验收包括滚轮缩放、中键拖动缩放、左键转动、右键平移、列表滚轮隔离、FOV 上下界以及摄影机手势不移动 Actor。原有冻结、Gizmo、Actor 变换、JSON、原版与测试 Mod 实体、捕获模式和退出恢复继续回归。

已知边界：可选桥接针对用户安装的 Skin Layers 3D 1.11.2。通过 ModelPart 渲染的类似皮肤层使用通用路径；完全替换渲染器或独立网格协议不保证兼容。特殊 CEM 资源包、未来的 Skin Layers 3D 签名改动、所有第三方装备未逐一验收。未安装 Skin Layers 3D 的发行包仍需正常启动，且没有新增动画或资产系统。

实际通过数量与证据见 `ACCEPTANCE.md` 和 `release/evidence/0.1.3`。
