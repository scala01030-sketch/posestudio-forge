中间失败保留在本地 build，不作为 PASS：新测试初次带入自然生成动物使固定数量断言不成立、直接删除实时实体迭代器产生空值，以及浮点精确比较导致失败，均为夹具修正。Wildfire 夹具在冻结后才初始化模型，使尚未更新的尺寸为零，已修正夹具准备。Core 夹具原先在退出 25 tick 后断言精确位置，将恢复后的普通移动也计入；改为在服务端还原调用后立即断言，其他四轮继续覆盖实际网络退出和装备还原。实际问题包括非玩家冻结后装备不同步、添加超限提示被后续同步覆盖，以及 Wildfire 呼吸未完全冻结，均已修复并完整重跑。Oculus / Physics 等第三方已有启动警告未作为本模组修复内容。
