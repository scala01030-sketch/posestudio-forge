# Pose Studio 0.1.8 — 物品目录与自动手持分离

只修复物品来源、摆拍对象读取和冻结入口；已有 Pose 编辑、连续关节、三轴控制、自由摄影机和十步撤回继续保留。

添加面板分为“实体”和“物品”。实体读取原版和 Mod 的 EntityType 注册表；物品读取非空气 Item 注册表，并合并当前世界的创造物品栏变体。同一 TaCZ 枪械物品 ID 下的 GunId、附件、皮肤等完整 ItemStack 数据不再丢失。可按本地化名称、注册 ID、Mod ID、GunId / ThrowableId 等变体数据搜索。物品目录按完整数据去重，只在打开面板并首次切换物品时建立，输入搜索不重新构建创造物品栏。第三方创造标签读取失败时保留注册物品降级，并记录原因。

成功冻结生物 / 玩家时，非空的主手和副手自动成为角色旁边的独立临时 ItemEntity。原角色暂时空手；人形模型首次建立 Pose 使用模型自己的中立初始姿态，避免捕获上一次持枪动作。后续用户编辑的 Pose 不再被初始化覆盖。分离出的物品立即同步到角色列表，可以在 Actor 模式中单独 XYZ 移动、Yaw / Pitch / Roll 旋转与撤回。物品使用原 Minecraft / Mod 地面物品渲染；无可读取 ModelPart 时只支持整体编辑，未伪造枪械内部骨骼。

冻结人形模型在当前渲染调用内使用站立基准，避免 TaCZ Tweaks 爬行、游泳插值或飞行造成整体倾斜；渲染外的原始运动姿态保留。对当前整合包的 Wildfire Gender 附加身体层补充躯干 Pose 同步，并冻结其原有物理更新和呼吸效果；FemalePlasticSurgery 的外形设置继续由原模组提供，未新增物理或关节系统。CarryOn 的搬运手臂姿态也接受已冻结 / 编辑 Pose 的覆盖。CarryOn 特殊搬运对象不是主副手 ItemStack，不自动转换为分离物品。

原装备完整数据和数量保存在恢复快照；展示物品数量为 1。恢复原角色、退出、登出或服务停止后，还原原热栏位置及副手，移除分离对象。玩家持有物品在冻结期间不能通过物品使用或物品栏操作改变；临时物品禁止拾取并无自动消失寿命。删除独立展示对象不删除原装备。持久快照用于中断后恢复，临时实体沿用原有孤立对象清理机制。

预先把所有将分离的非空手持物品计入非生物预算：默认 25，可配 20–30；生物 / 玩家仍默认 8，可配 5–10。超限时不清空装备、不部分冻结；生成失败时回滚。多人权限、锁所有权和同维度限制继续生效。添加物品使用完整 NBT 序列化，验证有效物品、大小和位置；网络协议升级为 5，多人双方必须同版。

旧版 0.1.7 保留，可用其独立 JAR 回退。真实测试和当前包的范围见 ACCEPTANCE-0.1.8.md。
