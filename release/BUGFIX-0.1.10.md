# Pose Studio 0.1.10 — 添加实体后动作界面自动就绪

添加场景实体后，服务端生成、客户端实体同步与模型部件的首次渲染是分步完成的。此前动作面板只处理骨骼列表从空变为非空；若后续才出现所选骨骼，面板会留下旧数值或失效节点，须重开界面。现在编辑面板按当前实体、选中骨骼和模型就绪状态更新，并在渲染模型与初始读取结构不一致时自动选一个可见骨骼。等待模型时数值不可编辑且有中英提示；普通帧不会清掉正在输入的值或焦点。

放置完成后先写入实体冻结状态和 Actor 变换，再刷新选中对象，避免短暂显示未冻结状态，也省去同一帧的重复面板重建。无 ModelPart 的实体仍可作为整个 Actor 摆放。本版只修正静态摆拍编辑界面；未添加动画或模型骨骼。
